# Face Recognition ด้วย KNN
โปรเจกต์จำแนกใบหน้าแบบ real-time ผ่านกล้อง โดยใช้อัลกอริทึม **K-Nearest Neighbors (KNN)** ที่เขียนขึ้นเองด้วย NumPy ไม่ใช้ library ML สำเร็จรูป

## วิธีการทำงาน
1. ถ่ายภาพใบหน้าในกรอบแดง แปลงเป็นภาพขาวดำ (grayscale) ขนาด 180×140 พิกเซล แล้วเก็บไว้ในโฟลเดอร์ โดยใช้ **ชื่อโฟลเดอร์เป็น label** ของแต่ละคน
2. ตอนตรวจจับ จะแปลงภาพแต่ละรูปเป็น vector (flatten) ยาว 25,200 ค่า
3. คำนวณระยะทาง (Euclidean Distance) ระหว่างใบหน้าในกล้องกับทุกรูปที่เก็บไว้
4. โหวตจาก k = 3 รูปที่ใกล้ที่สุด เพื่อระบุว่าเป็นใคร แล้วแสดงชื่อเหนือกรอบแดง

## ไฟล์ในโปรเจกต์
| ไฟล์ / โฟลเดอร์ | คำอธิบาย |
|---|---|
| `FaceTrain.py` | ถ่ายภาพใบหน้าผ่านกล้อง เก็บไว้ในโฟลเดอร์ชื่อคน |
| `FaceReg.py` | ตรวจจับใบหน้าแบบ real-time ผ่านกล้อง และจำแนกด้วย KNN (k=3) |
| `ชื่อคน/` | โฟลเดอร์ภาพใบหน้าของแต่ละคน (ไฟล์ `.jpg`) สร้างอัตโนมัติตอนรัน `FaceTrain.py` |

## ผลการทดสอบ
ทดสอบแบบ leave-one-out (หยิบรูปออกทีละ 1 รูป แล้วให้ KNN ทายจากรูปที่เหลือ) ด้วยข้อมูลทั้ง 315 รูป
ทายถูก **302/315 รูป = 95.9%**

## วิธีใช้งาน
รูปจะถูกเก็บและโหลดจากโฟลเดอร์ `face-recognition` เสมอ ไม่ว่าจะรันจากโฟลเดอร์ไหน (ถ้ารันจากนอกโฟลเดอร์ ให้ใส่ path เช่น `python face-recognition/FaceTrain.py`)

### 1. ถ่ายภาพใบหน้า (`FaceTrain.py`)
1. รันคำสั่ง
```bash
python FaceTrain.py
```
2. พิมพ์ชื่อคนที่จะถ่าย **เป็นภาษาอังกฤษ** แล้วกด Enter (OpenCV แสดงตัวอักษรไทยบนกล้องไม่ได้)
   - ถ้าเป็นชื่อใหม่ จะสร้างโฟลเดอร์ใหม่ให้
   - ถ้ามีโฟลเดอร์อยู่แล้ว จะถ่ายเพิ่มต่อจากเลขรูปเดิม ไม่เขียนทับ
   - ห้ามกด Enter โดยไม่พิมพ์ชื่อ โปรแกรมจะ error (ให้รันใหม่แล้วพิมพ์ชื่อ)
3. คลิกที่หน้าต่างกล้อง 1 ครั้ง แล้วขยับหน้าให้อยู่ในกรอบแดง
4. กด `s` ทุกครั้งที่อยากถ่าย เทอร์มินัลจะขึ้น `บันทึก ชื่อ/เลข.jpg` (คีย์บอร์ดต้องเป็นภาษาอังกฤษ ไม่งั้นกด `s` ไม่ติด)
5. กด `q`, `Esc` หรือปุ่ม X ที่หน้าต่าง เพื่อออกจากโปรแกรม

ตัวอย่างในเทอร์มินัล
```
ชื่อคนที่จะถ่าย: somchai
บันทึก somchai/1.jpg
บันทึก somchai/2.jpg
```

### 2. ตรวจจับใบหน้า (`FaceReg.py`)
1. ถ่ายภาพใบหน้าของแต่ละคนให้ครบก่อน (ขั้นตอนที่ 1) โปรแกรมจะโหลดรูปจากทุกโฟลเดอร์ โดยใช้ชื่อโฟลเดอร์เป็นชื่อคน
2. รันคำสั่ง
```bash
python FaceReg.py
```
3. หันหน้าเข้ากรอบแดง ชื่อคนจะขึ้นเป็นตัวสีเขียวเหนือกรอบ
4. กด `q`, `Esc` หรือปุ่ม X ที่หน้าต่าง เพื่อออกจากโปรแกรม
