# Face Recognition ด้วย KNN
โปรเจกต์จำแนกใบหน้าแบบ real-time ผ่านกล้อง โดยใช้อัลกอริทึม **K-Nearest Neighbors (KNN)** ที่เขียนขึ้นเองด้วย NumPy ไม่ใช้ library ML สำเร็จรูป

## วิธีการทำงาน
1. ถ่ายภาพใบหน้าในกรอบแดง แปลงเป็นภาพขาวดำ (grayscale) ขนาด 180×140 พิกเซล แล้วเก็บไว้ในโฟลเดอร์ โดยใช้ **ชื่อโฟลเดอร์เป็น label** ของแต่ละคน
2. ตอนตรวจจับ จะแปลงภาพแต่ละรูปเป็น vector (flatten) ยาว 25,200 ค่า
3. คำนวณระยะทาง (Euclidean Distance) ระหว่างใบหน้าในกล้องกับทุกรูปที่เก็บไว้
4. ใช้รูปที่ใกล้ที่สุด (k = 1) ระบุว่าเป็นใคร แล้วแสดงชื่อเหนือกรอบแดง
5. ใต้กรอบแสดงระยะถึงคนที่ใกล้ที่สุด (`d=`, ค่าพิกเซลต่างกันเฉลี่ย 0–255) และคนที่ใกล้เป็นอันดับ 2
   ถ้าสองคนนี้ระยะต่างกันไม่ถึง 2 จะขึ้น `(unsure)` แปลว่าก้ำกึ่ง

## ผลการทดสอบ
รัน `python evaluate.py` ด้วยข้อมูลทั้ง 421 รูป วัด 2 แบบ

- **leave-one-out**: หยิบรูปออกทีละ 1 รูป แล้วให้ KNN ทายจากรูปที่เหลือ
- **70/30 ตามลำดับเวลา**: เทรนด้วยรูป 70% แรกที่ถ่ายของแต่ละคน ทดสอบกับรูป 30% หลัง
  ใกล้เคียงการใช้งานจริงกว่า เพราะรูปที่ถ่ายติดกันหน้าแทบเหมือนกัน leave-one-out จึงทายง่ายเกินจริง

| k | leave-one-out | 70/30 ตามลำดับเวลา |
|---|---|---|
| **1** (ใช้อยู่) | **414/421 = 98.3%** | **117/130 = 90.0%** |
| 3 (ค่าเดิม) | 400/421 = 95.0% | 106/130 = 81.5% |
| 5 | 391/421 = 92.9% | 102/130 = 78.5% |

k = 1 แม่นที่สุดทั้งสองแบบ เพราะจำนวนรูปแต่ละคนต่างกันมาก (noppawan 154 รูป, anuwat 21 รูป)
ถ้าใช้ k = 3 คนที่มีรูปเยอะจะโหวตชนะคนที่มีรูปน้อยบ่อยขึ้น

## ข้อจำกัด
- ระบบทายเป็นคนใดคนหนึ่งในฐานข้อมูลเสมอ แม้กรอบว่างหรือเป็นคนที่ไม่มีในระบบ
  ลองใช้ระยะเป็นเกณฑ์ `Unknown` แล้วไม่ได้ผล เพราะกรอบสีเรียบ (ระยะ ~30) ใกล้พอ ๆ กับหน้าจริง (คนเดียวกันห่างกันได้ถึง ~45)
  จึงแสดงระยะและคนอันดับ 2 ให้ดูความมั่นใจแทน
- เทียบภาพขาวดำทีละพิกเซลในกรอบที่ตายตัว หน้าต้องอยู่ในกรอบแดงพอดี และแสงควรใกล้เคียงตอนถ่าย

## วิธีใช้งาน
รูปจะถูกเก็บและโหลดจากโฟลเดอร์ `face-recognition` เสมอ ไม่ว่าจะรันจากโฟลเดอร์ไหน (ถ้ารันจากนอกโฟลเดอร์ ให้ใส่ path เช่น `python face-recognition/FaceTrain.py`)

### 1. ถ่ายภาพใบหน้า (`FaceTrain.py`)
1. รันคำสั่ง
```bash
python FaceTrain.py
```
2. พิมพ์ชื่อคนที่จะถ่าย **เป็นภาษาอังกฤษ** แล้วกด Enter (OpenCV แสดงตัวอักษรไทยบนกล้องไม่ได้)
   - ถ้าเป็นชื่อใหม่ จะสร้างโฟลเดอร์ใหม่ให้
   - ถ้ามีโฟลเดอร์อยู่แล้ว จะถ่ายเพิ่มต่อจากเลขรูปเดิม ไม่เขียนทับ
   - ถ้ากด Enter โดยไม่พิมพ์ชื่อ หรือพิมพ์ภาษาไทย/อักขระพิเศษ โปรแกรมจะถามใหม่ (ใช้ได้ A-Z, a-z, 0-9, `_`, `-`)
   - เลขรูปต่อจากเลขที่มากที่สุดในโฟลเดอร์ จึงไม่เขียนทับรูปเดิม แม้เคยลบรูปบางรูปออก
3. คลิกที่หน้าต่างกล้อง 1 ครั้ง แล้วขยับหน้าให้อยู่ในกรอบแดง
4. กด `s` ทุกครั้งที่อยากถ่าย เทอร์มินัลจะขึ้น `บันทึก ชื่อ/เลข.jpg` (คีย์บอร์ดต้องเป็นภาษาอังกฤษ ไม่งั้นกด `s` ไม่ติด)
5. กด `q`, `Esc` หรือปุ่ม X ที่หน้าต่าง เพื่อออกจากโปรแกรม

ตัวอย่างในเทอร์มินัล
```
ชื่อคนที่จะถ่าย: somchai
บันทึก somchai/1.jpg
บันทึก somchai/2.jpg
```

### 2. ตรวจจับใบหน้า (`FaceReg.py`)
1. ถ่ายภาพใบหน้าของแต่ละคนให้ครบก่อน (ขั้นตอนที่ 1) โปรแกรมจะโหลดรูปจากทุกโฟลเดอร์ โดยใช้ชื่อโฟลเดอร์เป็นชื่อคน
2. รันคำสั่ง
```bash
python FaceReg.py
```
3. เทอร์มินัลจะแสดงจำนวนรูปของแต่ละคนที่โหลดได้
4. หันหน้าเข้ากรอบแดง ชื่อคนจะขึ้นเป็นตัวสีเขียวเหนือกรอบ
   ใต้กรอบเป็นสีเหลือง เช่น `d=18.2  2nd: anuwat d=27.5` (ยิ่งตัวเลขสองค่าห่างกัน ยิ่งมั่นใจ)
5. กด `q`, `Esc` หรือปุ่ม X ที่หน้าต่าง เพื่อออกจากโปรแกรม

### 3. วัดความแม่น (`evaluate.py`)
```bash
python evaluate.py
```
ไม่ต้องเปิดกล้อง ใช้รูปที่มีอยู่ แสดงผลแบบตารางด้านบน (ควรรันใหม่ทุกครั้งที่ถ่ายรูปเพิ่ม)
